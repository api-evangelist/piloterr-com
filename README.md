Piloterr provides a large library of over 500 web scraping APIs that enable structured data extraction at scale. Users can access endpoints for HTML parsing, JSON extraction, headless browser rendering, and specialized scrapers for e‑commerce, social media, and news sites. The platform offers a free tier with credits and paid plans for higher volume, along with detailed documentation, pricing tables, and a status page for service reliability.

**Areas:** Web Scraping · API · Data Extraction · Developer Tools · Headless Browser · Proxy Rotation · Anti‑Bot Bypass · SDKs

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Piloterr: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
